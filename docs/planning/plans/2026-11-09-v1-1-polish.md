## Global Constraints

- Only focus-segment running time is study time; `countdown` is a focus segment (spec §3.2, §6).
- `awayPrompt` default `true`; off disables idle polling, prompts and discards only. Suspend,
  lock and the 30 s unreported-sleep rule are unchanged (spec §3.1).
- `countdownMinutes` 1–240, default 60; presets 30 · 45 · 60 · 90 · 120 (spec §3.2).
- Countdown end: focus-done chime, notification title "Countdown done", body "{n} min of focus.",
  then idle in Countdown at full length; no break, no auto-start, `completedFocusCount` unchanged.
- Task change mid-segment splits the row like a subject change; rows store `task_id` and
  `task_text` (spec §3.3).
- `WidgetPos.scale` 0.5–2, default 1; `layoutScale = clamp(min(innerWidth/1920, innerHeight/1080), 0.5, 2)`;
  `LAYOUT_REF = { w: 1920, h: 1080 }` (spec §3.5).
- Images: up to 12; ≤ 20 MB; gif/png/jpg/webp by magic bytes; base fit 240 × 240 px; stored in
  `<userData>/images/<id>.<ext>`; links `https` only, downloaded once; CSP unchanged (spec §3.6).
- Image error copy, verbatim: "That isn't a GIF, PNG, JPEG or WebP image." · "That image is over
  20 MB." · "Couldn't download that link. Check it and your connection." · "You can have up to
  12 images. Remove one first."
- Focus view: `H` toggles; `Esc` exits when no overlay is open; "Show interface" capsule in the
  top-left 64 × 64 px; not persisted (spec §3.4).
- Renderer server URL `http://localhost:<port>`, still bound to `127.0.0.1`; YouTube 152/153 are
  persistent play errors, not embed blocks (spec §3.8).
- Schema migration v3 with a backup first; existing rows untouched (spec §5).
- British English, calm and short. No native modules. Electron security rules unchanged.

## Review Focus

1. **Countdown accrual.** Every place that tests `mode === 'focus'` to mean "study time" must use
   `isFocusMode`; one missed site silently drops or adds study minutes (today total, ledger,
   live accrual, checkpoint, chimes). Reviewer greps `'focus'` across `src/`.
2. **Away switch toggled mid-away** (open unprompted period vs showing prompt) and the R39 marker.
3. **Task split** keeps the pomodoro's day key (A3) and survives a crash (checkpointed row has
   `task_id`).
4. **Old settings** without `scale` / new keys load cleanly (per-field merge).
5. **Image download safety**: https only (also after redirects), size cap enforced while
   streaming (not after buffering an unbounded body), magic-byte check, protocol only serves
   registered ids.
6. **Scale + clamp**: a scaled widget never ends up off-screen or under the dock; drag maths uses
   the scaled box.
7. **Renderer origin change** (`localhost`): CSP application, the media protocol's CORS allowed
   origins and navigation blocking all follow the new origin.
