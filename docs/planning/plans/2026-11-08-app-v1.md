# StudyAt v1 (the whole app) — implementation plan

> Execute with `study-plan-execute` (self-contained; no superpowers skills). Steps use `- [ ]`.

**Goal:** Build the complete StudyAt desktop app (roadmap P1–P8) in one run: timer with honest
accounting, stats, spaces, soundboard and chimes, tasks, Spotify, tray, mini timer, installer.
**Spec:** `docs/planning/specs/2026-11-08-app-v1-design.md` (the spec wins where they disagree;
cited below as "spec §N"). Behaviour background: `docs/planning/appplan.md`.
**Roadmap:** P1–P8. **Worktree:** `.claude/worktrees/feat-app-v1`, branch `feat/app-v1`.

## Global Constraints

- study-dev rules 1–11 hold for every task (focus-only time, ≤ 15 s checkpoints, injected clocks,
  main-process timer, Electron security, no native modules, no LifeAt assets, deps added in WSL
  only, secrets via `safeStorage`, British English, `type(scope): sentence` commits, no AI
  attribution).
- Every file under `src/core/` is pure: no Electron, no Node `fs`, no `Date.now()`; time comes in
  as a parameter.
- Only Task 1 runs `npm install`. A later task needing a package not listed there logs a ruling
  and adds it with `npm install <pkg>` in WSL; never through `scripts/win.sh`.
- `STUDYAT_USER_DATA` overrides the data folder; tests never touch `%APPDATA%\StudyAt`.
- Values are verbatim from spec: focus/short/long **25/5/15**, long every **4**, checkpoint
  **15 s**, idle **10 min**, away auto-discard **2 min**, rollover **4**, streak **25 min**, goal
  **180 min**, backups keep **14**, auto-hide **5 s**, hotkey **Ctrl+Alt+P**, Spotify redirect
  **`http://127.0.0.1:43821/callback`**, poll **3 s**, segments under **60 000 ms** dropped.
- Copy strings come from spec §3.14 verbatim.
- Disk-lane agents never run `scripts/win.sh` or launch Electron. Only Task 19 does.

## Review Focus

1. **Away prompt while the window is hidden** (tray/mini): the prompt must still reach Sam (mini
   timer shows it, or the main window is shown) and the 2-minute auto-discard must fire even if
   no renderer is listening — Task 7 test `auto-discards after 2 minutes with no renderer`.
2. **sql.js file written while another write is in flight** (checkpoint + debounced flush
   overlap) must never leave a truncated file — Task 2 test `serialises overlapping flushes`.
3. **DST spring-forward night with a session at 01:30–03:30** must be credited once, to the
   previous day — Task 3 test `dst spring-forward session credited to previous day`.
4. **A space whose path contains spaces and non-ASCII** (`C:\Users\samue\Videos\café rain.mp4`)
   must stream with Range — Task 5 test `serves path with spaces and accents`.
5. **Hotkey pressed while a focus segment is paused by lock** resumes it explicitly (no double
   toggle) — Task 13 test `hotkey resumes a lock-paused timer once`.

## Task 4: Timer state machine (pure)

**Agent:** study-core (batched). **Files:** `src/core/timer/machine.ts`, `machine.test.ts`.

**Interfaces — produces:**

```ts
export interface TimerConfig { focusMs: number; shortMs: number; longMs: number; longEvery: number; autoStartBreaks: boolean; autoStartFocus: boolean }
export type TimerEvent =
  | { type: 'start' } | { type: 'pause'; reason: 'user' | 'suspend' | 'lock' } | { type: 'resume' }
  | { type: 'reset' } | { type: 'skip' } | { type: 'setMode'; mode: Mode } | { type: 'tick' } | { type: 'giveBack'; ms: number };
export interface MachineState { mode: Mode; status: TimerStatus; segmentMs: number; remainingMs: number;
  runningSince: number | null; completedFocusCount: number; pauseReason: PauseReason }
export type Effect = { type: 'focusStarted' } | { type: 'focusStopped'; reason: 'end' | 'skip' | 'reset' | 'mode' }
  | { type: 'segmentEnded'; mode: Mode; next: Mode } | { type: 'accrue'; ms: number };
export function initialState(cfg: TimerConfig): MachineState;
```
